# pertemuan-06 PHP Dasar dan Pemrograman Sisi Peladen

## Deskripsi

Pertemuan 6 membahas dasar PHP sebagai bahasa pemrograman sisi peladen (server-side) untuk mengembangkan halaman web dinamis. Pengembangan dilakukan dengan melanjutkan proyek P5 menggunakan Laragon dan PHP.

## Teknologi

HTML
CSS
script
PHP
Laragon
Git & GitHub

## Fitur yang Dikembangkan

Penggunaan variabel, konstanta, dan tipe data PHP.
Penerapan operator aritmetika, perbandingan, dan logika.
Percabangan if-elseif-else dan switch.
Perulangan for dan while.
Menampilkan konten halaman secara dinamis menggunakan PHP.

## Cara Menjalankan

Jalankan aplikasi Laragon.
Klik Start All.
Simpan folder proyek di direktori www Laragon.
Buka proyek melalui browser menggunakan localhost.
