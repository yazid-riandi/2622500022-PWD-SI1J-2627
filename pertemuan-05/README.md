# pertemuan-05 JavaScript Dasar, DOM, Event, dan Validasi Formulir

## Deskripsi

Pertemuan 5 merupakan pengembangan dari P4 dengan menambahkan fitur interaktif menggunakan JavaScript, seperti manipulasi DOM, event listener, navigasi responsif, dan validasi formulir.

## Teknologi

HTML5

CSS3

JavaScript

Git dan GitHub

## Fitur yang Dikembangkan

Menghubungkan JavaScript melalui file script.js.

Memanipulasi elemen HTML menggunakan DOM.

Membuat interaksi navigasi responsif.

Menerapkan event listener pada halaman.

Membuat validasi formulir sisi klien.

Menampilkan pesan validasi berhasil atau gagal.

## Struktur File

pertemuan-05/
├── img/
├── index.html
├── style.css
├── script.js
└── README.md

## Cara Menjalankan

Buka folder pertemuan-05/.

Jalankan file index.html menggunakan browser.

Uji navigasi dan formulir.

Periksa error melalui Browser DevTools dengan menekan F12.

## Pengujian

- Pengujian dilakukan pada:

Navigasi hamburger.

Validasi nama dan email.

Validasi semester dan tanggal.

Pilihan radio, checkbox, dan select.

Validasi pesan.

Tampilan umpan balik.
