# pertemuan-04 CSS3 Layout dan Responsive Web Design

## Pengembangan
- Perubahan yang dilakukan: [
    1. Pemisahan CSS
    Memindahkan CSS internal dari index.html ke file eksternal style.css.

    Menghubungkan style.css dengan index.html menggunakan elemen <link>.

    Memastikan tampilan halaman tetap berjalan dengan baik setelah pemisahan CSS.
    2. Penerapan CSS Box Model

    Menerapkan box-sizing: border-box pada seluruh elemen.

    Mengatur content, padding, border, dan margin.

    Menyesuaikan tata letak pada bagian Header, Home, Tentang Saya, Kontak, Formulir, dan Footer.

    3. Penerapan CSS Flexbox

    Menjadikan daftar navigasi (nav ul) sebagai Flex Container.

    Mengatur arah navigasi menggunakan flex-direction.

    Mengatur perataan elemen menggunakan justify-content dan align-items.

    Mengatur jarak antar-elemen menggunakan gap.

    Menghilangkan bullet serta mengatur tampilan tautan navigasi.

    4. Penerapan CSS Grid

    Menjadikan elemen main sebagai Grid Container.

    Mengatur tata letak utama menggunakan grid-template-columns.

    Menerapkan tata letak dua kolom dengan ukuran yang sama.

    Mengatur jarak antar-elemen menggunakan gap.

    Membuat bagian Kontak membentang pada seluruh kolom menggunakan grid-column.

    5. Penerapan Responsive Web Design

    Menggunakan pendekatan Mobile-First.

    Mengatur tampilan dasar menjadi satu kolom.

    Menerapkan media query dengan breakpoint 768px.

    Mengubah tata letak menjadi dua kolom pada viewport minimal 768px.

    Mengubah navigasi dari vertikal menjadi horizontal pada viewport minimal 768px.

    Menyesuaikan bagian Kontak agar memenuhi seluruh lebar Grid.
